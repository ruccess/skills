# 한국어 스킬 개선과 설치본 동기화 계획

일반 대화는 자연스러운 존댓말로 답하고, 독자에게 필요한 설명과 원문의 의미를 보존한다.
작업 보고의 명사형과 문서의 서술형은 용도와 사용자 요청에 맞춰 선택한다.

## 요구사항 추적표

원문은 이 대화의 사용자 요청과 직전 제안이며, 이 표는 2026-10-15 KST 기준 사본이다.

## 실행과 검증

1. 기존 스킬과 스킬 없는 응답을 새 평가 에이전트에서 확인한다.
   같은 과제와 판정 기준으로 변경 후 응답을 비교한다.
2. 두 스킬의 본문과 예시를 좁게 수정하고 README와 hook의 충돌하는 설명을 맞춘다.
   후보 표현의 출현 횟수와 실제 한국어 품질을 구분하는 평가 기준을 남긴다.
3. frontmatter·매니페스트 검사, 기존 평가 도구의 회귀 검사, hook 구문·출력 확인, diff 검사를 실행한다.
   한국어 문서는 독자 관점과 언어 점검을 서로 다른 맥락에서 검토한다.
4. 설치 폴더의 기존 내용을 백업하고 두 폴더만 저장소 링크로 바꾼다.
   링크의 대상과 파일 해시가 저장소와 일치하는지 확인한다.

## 판단과 위험

새 브랜치 feature/korean-quality-sync에서 작업한다.
사용자는 수정과 설치 동기화 이후 `main까지 올려줘`라고 요청해 원격 반영을 작업 범위에 추가했다.
원격 main에는 현재 브랜치의 이전 16개 커밋이 없어 전체 차이를 검토하고 이번 변경은 목적별 커밋으로 나눈다.
PR은 draft로 생성하고 원격 검증 결과와 함께 main 병합 범위를 확인한다.
스킬 본문은 영어로 유지하고, 한국어 예시는 본문 안에 둔다.
새 스킬이나 평가 실행기는 만들지 않는다.

설치 링크는 이 저장소의 현재 내용을 따른다.
따라서 저장소를 이동하면 링크를 다시 연결해야 하고, 브랜치를 바꾸면 설치 내용도 달라진다.
기존 설치 폴더는 저장소 밖에 보관해 복구할 수 있게 한다.
응답 평가 표본은 작으므로 결과를 일반적인 성능 향상으로 해석하지 않는다.

## 미결 질문

없다.
말투 기본값과 설명 우선순위는 직전 제안에 대한 사용자 승인으로 확정됐다.

## 실행 결과

두 한국어 스킬과 README·hook의 안내를 맞췄다.
최종 행동 평가는 사례마다 새 맥락을 사용해 21개 항목을 통과했다.
기존 설치본을 백업하고 Codex·Claude의 네 설치 경로와 저장소 파일의 일치를 확인했다.
초기 평가의 한계는 [평가 기록](../../../evals/findings-2026-10-15.md)에, 원본 응답과 개별 판정은 [평가 원본](../../../evals/korean-quality-results-2026-10-15.json)에 남겼다.
