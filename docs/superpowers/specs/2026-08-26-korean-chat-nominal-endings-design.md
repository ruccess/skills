# korean-chat 명사형 종결 전환 설계

## 목표

`korean-chat`의 기본 채팅 문체를 해라체 `~다`에서 명사형 종결 `~음/~함/~임/~됨`으로 바꾼다. Caveman의 압축 원칙을 한국어에 맞게 적용해 짧고 직접적으로 쓰되, 조사와 부정어처럼 의미를 결정하는 요소는 유지한다.

## 동작

- 여러 부분으로 된 답변의 결론, 세부 불릿, 다음 행동에 명사형 종결을 기본으로 쓴다.
- 완료한 일은 `~했음`, 현재 상태와 판단은 `~함/~임`, 수동 결과는 `~됨`처럼 의미에 맞게 쓴다.
- 모든 문장을 억지로 `~함`으로 끝내지 않고, 짧은 사실 답변이나 코드·오류 메시지는 자연스러운 원형을 유지한다.
- 존댓말 종결 `~요/~습니다/~십시오`는 사용하지 않는다.
- 위험하거나 되돌리기 어려운 작업의 경고와 순서가 중요한 절차에서는 압축 강도만 낮춘다. 문장을 명확하게 완성하되 명사형 종결은 유지한다.
- Caveman처럼 인사·헤징·중복·진행 예고를 제거하고 짧은 단어를 선호한다. 기술 용어·코드·오류·부정어·수치·단위는 정확히 보존하며, 억지 축약어나 깨진 문법은 만들지 않는다.
- 인사말, 헤징, 질문 재진술, 불필요한 결론 반복을 제거하는 기존 규칙은 유지한다.

## 변경 범위

`skills/korean-chat/SKILL.md`의 기본 형태와 예시를 고친다. 같은 동작을 설명하는 `README.md`와 `docs/test-scenarios.md`도 함께 바꾸고, 동작 변경에 맞춰 플러그인 버전을 세 매니페스트 위치에서 동일하게 올린다.

저장소의 일반 문서 문체는 `CONTRIBUTING.md`의 완결 산문 규칙을 유지한다. 이번 변경은 문서 전체를 함체로 바꾸는 작업이 아니라, `korean-chat`의 새 동작을 설명하는 모든 문서와 예시를 일치시키는 작업이다.

Caveman 압축 규칙은 [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)의 MIT 라이선스 스킬에서 증류하며, `korean-chat` 본문과 기여 문서에 출처를 밝힌다.

## 검증

현재 스킬로 장애 공유 메시지를 생성해 해라체가 나오는 RED 사례를 기록한다. 수정 후 같은 입력으로 모든 산문 종결이 명사형을 쓰고 존댓말이 0회인지 확인한다. Caveman 압축, 불릿, 조사, 금지 표현, 기술 정보 보존 기준도 함께 대조한다. 마지막으로 `node scripts/validate.mjs`를 실행해 스킬과 매니페스트 일관성을 검증한다.
