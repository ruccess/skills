# 한국어 스킬의 말투와 의미 보존 평가

2026-10-15에 한국어 스킬의 우선순위를 의미와 근거, 독자에게 필요한 설명, 자연스러운 말투, 간결함 순으로 조정했다.
초기 평가는 gpt-6-luna의 medium 추론 설정으로 스킬 없는 기준선, 변경 전 스킬, 변경 후 스킬에 같은 다섯 요청을 주는 방식으로 진행했다.
초기에는 각 조건을 새 에이전트에서 실행했으며, 한 조건 안의 다섯 사례는 같은 평가 맥락을 사용했다.
따라서 사례 간 영향을 완전히 배제한 반복 실험은 아니다.

## 초기 관측 결과

| 조건 | 통과 항목 | 관측 |
| --- | --- | --- |
| 스킬 없음 | 19/19 | 이번 과제에서는 기본 응답도 모든 항목을 통과했다 |
| 변경 전 스킬 | 17/19 | 일반 대화 두 사례에서 기본 명사형 규칙 때문에 존댓말 기준을 충족하지 못했다 |
| 변경 후 스킬 | 19/19 | 일반 대화는 존댓말을 쓰고, 요청한 작업 보고는 명사형을 유지했다 |

변경 전 캐시 설명은 `캐시는 자주 쓰는 정보를 잠시 저장해 두었다가 다시 꺼내 쓰는 공간임.`으로 시작했다.
변경 후에는 `캐시는 나중에 다시 쓸 정보를 잠시 저장해 두는 공간이에요.`로 시작했다.
두 응답 모두 캐시의 뜻과 사용 이유, 사진을 다시 보여 주는 예시를 설명했다.
따라서 이번 비교로 설명 능력의 향상을 입증하지는 않았다.

작업 상태 응답은 테스트 14개 통과, 운영 배포 미실시, 실제 사용자 속도 미측정을 구분했다.
남은 시간을 지어내지 않았고, 문서 교정에서도 가능성·예측·초당 3천 건·help.md·DB_CONNECTION_EXHAUSTED와 세 가지 속성을 보존했다.
해당 항목은 기준선도 통과했으므로 개선 효과로 집계하지 않는다.

## 최종 확인

초기 평가에는 문서 기본 서술형을 직접 판정하는 항목이 빠져 있었다.
실제로 초기 변경 후 응답은 두 문서 사례에 존댓말을 사용했다.
문서의 기본값을 `~한다/~이다`로 명확히 하고 문서체 기준 두 개를 추가했다.
이후 최종 다섯 사례는 각각 새 에이전트에서 실행해 21개 항목을 모두 통과했다.
일반 대화의 존댓말, 요청한 보고의 명사형, 문서의 기본 서술형을 확인했다.
최종 판정 항목과 실행 맥락이 초기 평가와 다르므로 19개 기준의 초기 점수와 직접 비교하지 않는다.

## 평가의 범위

요청과 항목별 기준은 [`korean-quality-cases.json`](korean-quality-cases.json)에 고정했다.
평가 에이전트가 응답과 항목별 판정 이유를 남겼고, 주 에이전트가 실제 응답을 다시 확인했다.
초기·후속·최종 응답, 개별 판정 이유, 최종 스킬 해시는 [`korean-quality-results-2026-10-15.json`](korean-quality-results-2026-10-15.json)에 보존했다.
변경 전 스킬은 커밋 `45374e3`이며, [행동 평가 절차](../docs/test-scenarios.md#설명말투의미-보존-회귀)에 입력 구성과 재현 방법을 적었다.
조건당 한 번 실행한 작은 표본이므로 모델 전반의 한국어 성능이나 반복 실행의 일관성을 보장하지 않는다.
자동 정규식 점수는 후보 표현의 출현 횟수이며, 이 평가의 문맥 판정을 대신하지 않는다.

## 설치 동기화 방식

두 한국어 스킬의 기존 설치 폴더를 `~/.codex/skill-backups/korean-quality-20261015-Zz9aMc`에 옮겨 보존했다.
`~/.agents/skills/korean-chat`과 `korean-docs`를 이 저장소의 해당 스킬 폴더에 연결했다.
기존 `~/.claude/skills` 링크도 같은 경로를 참조한다.
Codex와 Claude의 네 설치 경로가 저장소의 해당 폴더로 해석되고, SKILL.md의 SHA-256이 저장소 파일과 일치함을 확인했다.
저장소를 이동하거나 브랜치를 바꾸면 설치 내용에 영향을 준다.
설치 경로와 링크 지원은 [공식 스킬 안내](https://learn.chatgpt.com/docs/build-skills)를 확인했다.

복구할 때는 `~/.agents/skills`의 두 설치 경로가 링크인지 확인하고 링크만 제거한 뒤, 백업 폴더 안의 같은 이름 폴더를 원래 경로로 옮긴다.
`~/.claude/skills`의 기존 링크는 그대로 둔다.
