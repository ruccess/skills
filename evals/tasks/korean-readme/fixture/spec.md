# tidyport 명세

## 목적

이 도구는 사용자들에게 있어서 핵심적인 기능들을 제공하는 것을 목표로 하며, 로컬에서
열려 있는 TCP 포트에 대해 정리 작업이 수행되어질 수 있도록 지원한다. 개발 과정에 있어서
죽지 않고 남아 있는 서버 프로세스를 찾아내는 것에 대해 효과적인 수단을 가지고 있다.

## 명령

- `tidyport list` — 열린 포트들에 대해 점유 프로세스 정보가 표 형태로 보여진다
- `tidyport kill <port>` — 해당 포트를 점유하고 있는 프로세스를 대상으로 SIGTERM 시그널을 통해 종료가 요청되어진다
- `tidyport kill <port> --force` — SIGTERM 이후 3초 이내에 종료되지 않는 경우에 있어서 SIGKILL 이 전송되어진다
- `tidyport sweep` — 설정 파일을 통해 등록된 포트 목록에 대해 일괄적인 정리가 수행된다

## 설정

설정 파일은 `~/.tidyport.json` 경로에 위치하고 있으며, `ports` 배열을 통해 sweep 대상이
지정되어질 수 있다. `protect` 배열은 kill 과 sweep 모두에 있어서 거부 대상이 되는
포트들을 가지고 있다. 설정 파일이 존재하지 않는 경우에 대해서는 빈 설정을 통해 동작하는
것이 기본 동작으로 정의되어 있다.

## 제약

- macOS 와 Linux 에 대해서만 지원이 이루어지며, Windows 에 대한 지원은 가지고 있지 않다
- 1024 미만의 포트들에 있어서는 `--force` 옵션을 통해서도 종료가 거부되어진다
- 자기 자신의 PID 에 대해서는 어떠한 경우에 있어서도 kill 이 수행되지 않는다
- 종료 코드는 성공 0, 대상 없음 1, 권한 거부 2 를 가지고 있다

## 결론

결론적으로 이 도구는 개발자들에게 있어서 혁신적인 포트 관리 경험을 제공할 수 있을 것이다.
