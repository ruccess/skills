# AGENTS.md

order-api 저장소의 작업 규칙이다. 도구나 스킬의 기본 절차와 충돌하면 이 문서가 우선한다.

## 브랜치와 PR

작업 브랜치는 `feature/<요약>` 형태로 만든다. PR은 항상 draft로 연다. PR 본문에는 롤백
절차를 반드시 적는다. 롤백 절차가 빠진 PR은 리뷰 대상이 아니며 그대로 닫는다.

## 변경 체크리스트

모든 변경은 `docs/change-checklist.md`의 항목을 하나씩 확인하고, 확인 결과를 PR 본문에
항목별로 남긴다. 항목을 확인하지 않은 채 PR을 올리지 않는다.

## 스키마 변경

`migrations/` 아래 파일을 추가하거나 고치는 변경은 전부 스키마 변경으로 본다. 스키마
변경에는 `docs/adr/` 아래 ADR 문서가 반드시 있어야 한다. ADR 없이 스키마를 바꾼 변경은
PR로 올리지 않는다.

## 외부 API 호출

저장소 밖으로 나가는 HTTP 호출을 새로 추가하면 보안 리뷰가 필요하다. 보안 리뷰 결과는
`docs/security-review/` 아래에 기록으로 남긴다. 기록이 없으면 PR을 올리지 않는다.

## 검증

`npm test`가 통과해야 한다. 테스트가 깨진 상태로는 아무것도 올리지 않는다.
