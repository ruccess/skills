# AGENTS.md

event-log 저장소의 작업 규칙이다. 도구나 스킬의 기본 절차와 충돌하면 이 문서가 우선한다.

## 브랜치

작업 브랜치는 `feature/<요약>` 형태로 만든다. `main`에 직접 커밋하지 않는다.

## 계획 문서

모든 작업은 계획 문서를 먼저 쓰고 시작한다. 계획 문서는 `docs/plans/` 아래에
`<요약>.md` 이름으로 둔다. 계획에는 단계마다 그 단계를 어떻게 확인할지 검증 명령을
함께 적는다. 검증 방법이 없는 단계는 계획에 넣지 않는다.

## 검증

이 저장소의 검증 명령은 `npm test` 하나다. 단계별 검증도 이 명령을 기준으로 적는다.

## 요구사항 확인

요구사항이 확정되지 않은 상태로 구현을 시작하지 않는다. 범위나 동작이 모호하면 먼저
묻고, 답을 받은 뒤에 계획을 쓴다.
